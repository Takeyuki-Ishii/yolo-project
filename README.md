# 🎬 動画対応！車・自転車の交通量自動検知＆追跡アプリ

AI（YOLOv8）を活用し、アップロードされた動画から自動車や自転車の交通量をリアルタイムで自動検知・トラッキング・可視化するWebアプリケーションです。

## 🚀 アプリケーションURL
[アプリを試してみる（Streamlit Cloud）](https://yolo-project-ggq8x8moncm4qotxe2jghf.streamlit.app/)

※Streamlit Cloudの制約上、約12時間アクセスがないとシステムがスリープ状態となります。スリープ状態でユーザーがアクセスした際に "Yes, get this app back up!" というボタンが画面表示されるので、ボタンを押しアプリが再起動するまで(3分程度)お待ちください。

## 🎯 開発の背景と目的

### 解決したい課題
従来の道路交通量調査は、調査員が現地でカウンターを用いて手作業で計測しており、人件費の削減や天候による影響、人為的ミスの防止が長年の課題となっています。また、録画データがある場合でも、手作業での見直しには膨大な時間がかかります。

### 制作目的
本システムは、「動画をアップロードするだけ」で、AIが24時間いつでも正確に、かつ瞬時に交通量を計測・データ化できる仕組みを提供し、交通量調査の圧倒的な効率化とコスト削減を目指して開発しました。

### 想定利用者
- 自治体の都市計画・交通政策担当者
- 商業施設の出店計画のための交通量リサーチを行うマーケティング会社
- 道路状況のモニタリングを行いたいインフラ管理企業

## 🛠️ 主な機能
- **マルチオブジェクトトラッキング**: 自動車（トラック含む）と自転車を個別に認識し、同一物体に一意のID（Track ID）を付与して重複なく追跡
- **リアルタイムメトリクス更新**: 解析中の画面内に現在何台の車両が存在するかをリアルタイムに数値表示
- **インタラクティブな時系列グラフ可視化**: 経過時間ごとの検知台数の推移をグラフ（Altair）で動的に描画
- **データエクスポート**: 解析したフレームごとのTrack ID、検知クラス、時間データをCSVとしてワンクリックでダウンロード可能
- **パフォーマンス最適化設定**: サーバー負荷やネットワーク環境に応じ、ユーザーが「フレーム間引き間隔」や「解析解像度（横幅）」を自由に調整可能
- **厳密なファイルバリデーション**: サーバー保護のため、20MB以内、30秒以内の動画のみを受け付ける制限ロジックを実装

## 💡 技術的な工夫とこだわり（エンジニア視点）

### 1. 限られたクラウド環境（無料枠CPU）でのメモリ最適化
Streamlit Cloudの無料コンテナ（メモリ約1GB制限・GPUなし）で動画解析を回すと、メモリ不足（OOM）でクラッシュする課題がありました。
- **対策:** YOLOの推論に `stream=True` を指定してジェネレータ化し、全フレームの推論結果をメモリに蓄積させず1フレームずつ使い捨てる構造にリファクタリング。
- **対策:** `torch.no_grad()` による勾配計算の無効化、および毎フレーム不要になった画像オブジェクト（Numpy配列）を `del` 文で明示的にメモリから解放することで、高画質設定でもクラッシュしない安定性を確保しました。

### 2. 中断・エラー発生時における防御的プログラミング
ユーザーが解析の途中でブラウザの「Stop」ボタンを押したり画面を閉じた際、動画のファイルポインタが開いたままになり、サーバーのリソースを圧迫し続けるリスクがありました。
- **対策:** 解析コアロジックを `try ... finally` 構文でカプセル化。処理がどのように中断されても、`finally` ブロック内で確実に OpenCV の `cap.release()` が呼び出され、動画ファイルを安全にクローズする堅牢なライフサイクル管理を徹底しました。

## 📹 テスト用動画の入手方法（ご利用者様へ）

本アプリの動作を確認するためのテスト用動画をお持ちでない場合は、商用利用可能かつクレジット表記不要のフリー動画サイトからダウンロードしてご利用いただけます。

### 1. おすすめのフリー動画サイト
- **[Pixabay（ピクサベイ）](https://pixabay.com)**：高画質でスマートな交通量動画が豊富です。
- **[Pexels（ペクセルズ）](https://pexels.com)**：街並みやドローン空撮のシネマティックな動画が多く揃っています。

### 2. 推奨の検索キーワード
各サイトの検索窓に以下のキーワードを入力（英語での検索がよりヒットしやすくおすすめです）して動画を探してみてください。
- `traffic`（交通、行き交う車）
- `city traffic`（都会の交通量）
- `bicycle street` / `cycling`（自転車が通る道路）
- `highway` / `road`（高速道路・一般道）

### 3. 本アプリで正常に解析するためのダウンロード手順
1. 上記キーワードで検索し、**「自動車や自転車が複数台、画面内を移動している動画」**を選びます。
2. サーバー負荷軽減の制限（20MB以内、30秒以内）を満たすため、ダウンロード時の解像度は **`1280×720 (HD)`** または **`640×360`** などの軽量なものを選択してください。
3. もしダウンロードした動画が30秒を超えている場合は、あらかじめお手元のスマートフォンやPCの標準機能で「30秒以内」にトリミング（切り出し）してからアップロードしてください。
